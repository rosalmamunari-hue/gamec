Every connection the panel makes to a node (SSH, status checks, host keys) can be sent through one jump host, so the nodes see its address and never the panel's. It uses SSH forwarding: nothing extra to install on the jump host, and its account cannot open a shell or run a command. If the jump host cannot be used, connections fail; they never quietly go direct.
