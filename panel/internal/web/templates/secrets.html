贴一个 Cloudflare 令牌

令牌是在 Cloudflare 后台建的一串字，可以随时作废，比账号密码安全。不需要 Zone ID。

  1. 登录 Cloudflare，右上角头像 → My Profile → API Tokens → Create Token。
  2. 选「Edit zone DNS」那个模板，点 Use template。
  3. 「Zone Resources」选 Include → Specific zone，只选你要用的域名（两个域名就加两条）。不要选全部域名。
  4. 一路点下去创建。令牌只显示一次，整串复制贴到下面。
之后在渠道的「域名」里用这个名字。第一次用就保持 main；同名再保存一次就是换新令牌。
