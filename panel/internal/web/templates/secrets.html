Cloudflare 令牌

令牌就是在 Cloudflare 後台建出來的一長串字（常以 cfat_ 開頭，或是一串亂碼）。不需要填 Zone ID，面板會自己用域名去查。

怎麼建這個令牌（約 1 分鐘）
  1. 登入 Cloudflare，右上角頭像 → My Profile → API Tokens → Create Token。
  2. 選「Edit zone DNS」那個範本，點 Use template。
  3. 「Zone Resources」那裡選：Include → Specific zone，只選你要用的域名（用兩個域名就各加一條）。不要選全部域名。
  4. 一路點下去建立，只會顯示一次，複製整串貼到下面。
