Cloudflare 令牌

令牌就是在 Cloudflare 后台建出来的一长串字（常以 cfat_ 开头，或是一串乱码）。不需要填 Zone ID，面板会自己用域名去查。

怎么建这个令牌（约 1 分钟）
  1. 登录 Cloudflare，右上角头像 → My Profile → API Tokens → Create Token。
  2. 选「Edit zone DNS」那个范本，点 Use template。
  3. 「Zone Resources」那里选：Include → Specific zone，只选你要用的域名（用两个域名就各加一条）。不要选全部域名。
  4. 一路点下去创建，只会显示一次，拷贝整串贴到下面。
